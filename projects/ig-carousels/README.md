## 資料夾命名

新的圖卡資料夾建議用 `sexpsy_ig_<文章關鍵字>`，對應網站文章的 slug，例如 `sexpsy_ig_coexist_addiction` 對應 `addiction-note07-coexist-with-addiction`。

## 常用操作

- 做新圖卡：先確認文章已上線，再依文章所屬系列，挑 `exports/` 裡對應主題的版型。
- 文章文字以網站上的版本為準；圖卡上的文字同樣遵守 `CLAUDE.md` 的文風與隱私原則。
